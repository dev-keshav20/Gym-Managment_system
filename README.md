# 🏋️ Gym Management System

A fully responsive Gym Management System website built using HTML, CSS, and JavaScript. This project is designed to help gym owners manage their clients, display services, and maintain a professional online presence.

## 🚀 Features

- Clean and modern UI  
- Responsive design for mobile and desktop  
- Member registration form (static)  
- Services section (Plans, Trainers, Contact)  
- Smooth navigation and scrolling  

## 🛠️ Tech Stack

- **HTML**  
- **CSS**  
- **JavaScript (Vanilla)**
